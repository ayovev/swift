window), with every session behind each verdict. Produced from `public/sample/sugarwod-sample-export.csv`
by a throwaway test; the values are estimated 1RM (a benchmark shows its raw score) rounded to the
nearest whole number, so a percentage here can differ in the last digit from one computed on the
unrounded values. "(test)" marks a session whose title or description names an explicit rep max or a
rep ladder. The record check compares each recent session with the best of **all** earlier sessions.
The last line of each block shows where "3% or a record" and "5% or a record" would differ; only Back
Squat does.
